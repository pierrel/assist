#+title: Phone API client-local pins supersession

* Decision

This note supersedes only the pinning portion of
=2026-09-04-phone-api.org=. Pins are client-side UI state unless Pierre
explicitly directs otherwise. The phone API neither receives nor stores pins,
and Assist does not synchronize them between clients.

* Effect

The server-side =/pins= endpoints and =phone-pins.json= store are removed.
The existing browser thread UI continues to keep its own bounded pins in
browser localStorage. The Emacs phone client will likewise own its local pins.
