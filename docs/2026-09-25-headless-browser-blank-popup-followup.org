* Implementation correction
The =Solution= section of =2026-09-25-headless-browser-round4-corrections.org=
already allowed initial =about:blank= before a page reaches HTTP(S), but the
first implementation closed that popup during observation. An initial blank
popup now returns an empty observation and stays open for reuse. No page
content or targets are returned until it reaches HTTP(S). A return to
=about:blank= after HTTP(S), or navigation to another non-HTTP(S) scheme,
still closes the page.

* Verification
The original real-Docker test asserts a distinct popup page ID and
=about:blank= URL. The new unit regression checks that blank content is not
read and that the popup stays open.
